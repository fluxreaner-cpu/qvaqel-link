# QVAQEL · Платформа для разведки открытых источников

Многостраничный сайт про OSINT, GEOINT и смежные дисциплины.

## Структура

- `index.html` — главная страница
- `about.html` — о проекте
- `tools.html` — каталог инструментов с фильтрацией
- `methodology.html` — методология расследований
- `geoint.html` — раздел GEOINT
- `contact.html` — контактная форма
- `styles.css` — общие стили
- `script.js` — общие скрипты
- `netlify.toml` — конфигурация для Netlify

## Деплой на Netlify

1. Загрузите все файлы в репозиторий GitHub
2. Подключите репозиторий к Netlify
3. Настройки сборки:
   - Build command: `echo 'No build command needed'`
   - Publish directory: `.`
4. Нажмите "Deploy site"

Или просто перетащите папку с файлами в интерфейс Netlify Drop.

## Особенности

- Полностью статический сайт (HTML/CSS/JS)
- Адаптивный дизайн
- Анимации появления элементов
- Интерактивный терминал с эффектом печати
- Фильтрация инструментов по категориям
- Рабочая контактная форма (требует backend или сервис типа Formspree)
- Параллакс-эффект на фоне
- SVG-баннер QVAQEL
